# 网页快开

像启动应用一样，即刻打开网页。需要包含网页启动接口和本插件包指纹的 WTools **0.6.8** 或更新版本。

- 新建分类，添加名称和网址。一个入口最多放 30 个网址，每个网址可单独选择默认浏览器、Edge、Chrome 或 Firefox。
- 点击名称打开入口的全部网址；「打开此分类」打开分类内所有已启用入口。同一浏览器的相同网址会去重，一次最多提交 100 个网址。
- 关闭入口开关后，不参与打开、分类启动和启动器搜索。
- 开启「分类启动」，并在宿主插件详情打开「搜索栏推送」，可搜索 `网页快开 名称`，选中网页或分类直接启动。
- 「常用网站」和「AI 快开」提供可编辑的初始入口。AI 快开直接访问网站，使用网站自身的对话、上传和登录功能。
- 配置通过宿主 `dbStorage` 本地保存；普通浏览器预览使用 `localStorage`，实际启动需要 WTools。

检测 Windows 的 LOCALAPPDATA、Program Files 和 Program Files (x86) 下标准位置安装的浏览器。便携版、自定义安装位置可通过系统默认浏览器使用。仅接受不带账号密码的 HTTP / HTTPS 网址。显示「已向浏览器提交」表示启动请求成功，不代表网站加载完成。

## 验证入口

1. 导入 ZIP 或注册本目录。搜索「网页快开」及「AI 快开」，应分别进入相应页签。
2. 新建分类和包含两个网址的入口，其中一个网址选择 Edge，另一个选择默认浏览器。保存并重新打开，确认配置保留；点击名称应提交两个网址。
3. 关闭入口后点击「打开此分类」，确认只启动启用项；没有启用项时不能提交。
4. 开启分类启动与宿主搜索栏推送，搜索 `网页快开 分类名`，选择分类结果应启动所有启用项。搜索网页名称并选择结果应启动该入口。
5. 删除自定义分类，其网页应移到默认分类；取消编辑与 Esc 应保留原数据。
6. 无效地址应阻止保存；未安装浏览器应提示更换；旧宿主应提示升级。

开发检查：仓库根目录运行 `node --test tests/web-launcher.test.cjs` 和 `python scripts/build_catalog.py`。真实 WebView2 与外部浏览器联动需在新宿主上验收。

浏览器交互验证：先运行 `npm install --prefix dist/qa playwright-core --no-audit --no-fund`，再运行 `node tests/web-launcher-browser.cjs`。脚本使用本机标准位置的 Edge 无头模式，模拟宿主存储和启动接口，覆盖增删改、持久化、停用过滤、分类启动载荷、网址校验、AI 页签和窄窗口布局。截图写入 `dist/web-launcher-*.png`。
