# 合社日历

有温度的中国风日历，基于 [scutken/he-calendar](https://github.com/scutken/he-calendar) 1.6.0 适配，WTools 插件版本为 1.6.3。原作者为阿裕Addyu，遵循 MIT 协议。本版加深浅色模式下的年月、导航按钮和星期标题文字，提升可读性。

## 使用

需要包含通用网络接口 `wtools.request` 和外链接口的 WTools 构建；早期 **0.6.8** 构建不具备通用网络接口，不能只按版本号判断。日历作为普通 Web 插件运行，无需专用天气权限或宿主包指纹。重新构建配套宿主后，在已安装插件中注册本目录，或在发布后从插件市场安装。通过「合社日历」「日历」「万年历」「黄历」「calendar」打开。

- 离线显示公历、农历、黄历宜忌、干支、生肖、十二时辰、传统节日与二十四节气。
- 保留节气自动配色、中国风主题、明暗模式、节日倒数和日期距离。
- 点击年份或月份快速跳转，点击箭头或滚轮切月，「今天」回到当天。
- 主题和显示偏好通过 WTools `dbStorage` 保存；浏览器预览使用 `localStorage`。
- 在设置的「天气显示」中搜索至少两个字的城市名称，点击结果添加，最多保存五个城市。可切换城市、拖动排序、删除城市或关闭天气。
- 顶部天气摘要显示当前天气，悬停查看逐小时与未来四天预报；数据每三十分钟刷新，失败时可点击重试。城市列表和当前城市会保存，天气数据在联网后重新获取。
- 设置中的项目链接及节日百科按钮直接交给系统默认浏览器打开，失败时显示提示。

天气使用小米天气服务，需要联网；城市搜索与天气预报由插件通过通用 `wtools.request` 请求，上游地址、参数和数据处理均位于插件内，不再依赖日历专用天气路由或自动地理定位。普通浏览器预览通过浏览器 `fetch` 请求，会受上游 CORS 限制，不保证天气可用。没有接入 uTools AI tools 或 Electron preload。节假日和调休信息以随包历法数据为准，不会联网更新。

本目录包含可直接运行的生产资源，复用 https://cal.heshe.tech 在 2026-11-24 提供的 1.6.0 编译产物，不依赖示例站在线运行，也不需要 Node.js。

上游 CSS 与图标原样保留，`wtools.css` 单独补充浅色导航文字对比度、小窗适配及提示样式；JS 保存为 `assets/he-calendar.js`，将 `window.utools` 调用改为独立的 `window.heCalendarHost` 适配对象，天气 API 基址使用 `https://weatherapi.market.xiaomi.com/wtr-v3/`，请求经 `heCalendarHost.request` 调用通用宿主桥接。天气界面沿用上游实现。`wtools.js` 负责存储、生命周期、网络及外链调用，不改写宿主注入的全局 API 或全局 `fetch`。页面「关于」显示上游版本 1.6.0，插件清单暂保留 1.6.3；本次未发布新版本。

升级上游资源时应根据新源码重新定位这些适配点，保留上游署名、许可证及 `THIRD-PARTY-LICENSES.txt`。宿主已删除日历专用天气路由、Calendar 权限和包指纹分支，不保留旧版日历兼容逻辑。修改插件内容不需要再次修改宿主；网络通过通用请求、外链通过 `wtools.shellOpenExternal(url)` 完成。使用本版需要包含通用联网能力的宿主，旧插件请更新为本目录中的实现。

已执行浏览器功能和多尺寸回归，并在实际 WTools WebView2 中验证窄窗布局与通用网络桥接；使用广州公开坐标请求小米天气返回 HTTP 200。宽度不超过 600 且高度不超过 360 逻辑像素时，月视图仅显示清晰的公历日期，所选日的农历仍保留在详情区。城市添加、切换、排序、保存及请求失败后的日历可用性使用隔离样本验证；默认浏览器外链未在本轮实际打开。市场 ZIP 和目录索引由仓库现有发布工作流生成。
