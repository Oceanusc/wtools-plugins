# PDF 处理

独立的 WTools 离线 Web 插件，最低宿主版本 0.6.7，不需要新增原生接口。文件不上传、不持久化，下载沿用仓库现有的 Blob 下载方式。市场登记在根目录 `plugins.json`；源文件选择、输出保存依赖宿主 WebView 的文件选择和下载支持。

## 功能

| 工具 | 行为 |
| --- | --- |
| PDF 压缩 | 基本压缩优化对象流并保留文字与矢量内容；强压缩按页渲染为 JPG，可调 DPI 和质量。输出未变小时返回原文件。 |
| PDF 合并 | 合并 PDF、PNG、JPG、WebP；拖动或按钮排序、旋转文件的全部页面、显示页面并逐页排除。 |
| PDF 拆分 | 每页一份、固定页数一份，或提取指定页为一份 PDF。 |
| PDF 水印 | 中文文字、字号、颜色、边距、角度、透明度、九宫格位置和平铺；文件预览显示实际水印效果。 |
| 提取图片 | 提取内嵌位图为 PNG，可设置最小边长及同一资源去重；不提取矢量图或将其伪装为图片。 |
| PDF 转图片 | 指定范围逐页导出 PNG / JPG，可调分辨率和 JPG 质量。 |
| PDF 转 Word | 输出 DOCX：提取可编辑文字，或用页面图片保留外观。文字模式不保留复杂排版、图片、表格。 |
| PDF 转 PPT | 输出 PPTX：每页一张图片幻灯片，按第一页确定比例，其他页面等比适配。文字不可单独编辑。 |
| PDF 转 Excel | 输出 XLSX：每页一个工作表，按文字位置推测列，也可每行放入一列。所有提取内容作为文字写入，不执行公式。 |

不包含 OCR。扫描件可转图片、图片模式 Word 或 PPT；无文字层的文件无法提取可编辑文字或 Excel 数据。基本压缩不保证减小体积；强压缩丢失可选择文字和链接、表单、批注等交互能力。修改后的 PDF 不保留有效的数字签名。

## 使用

- 用启动器搜索「PDF 处理」或对应工具名称打开。
- 点击添加文件、Ctrl+O 或拖入文件。Ctrl+Enter 开始。
- 页码范围支持 `1-3,5,8-10`，留空为全部。范围分别应用于每个文件，超出当前文件页数会报告该文件错误。
- 队列在工具间共用；图片仅用于合并。切换工具、参数或文件队列会清空旧处理结果，下载后再调整。
- 结果可以逐个下载，多个结果可打包 ZIP 下载；ZIP 内同名文件自动增加序号。
- 取消在当前页面或编码任务结束后生效。批量任务中，已完成文件的结果仍可下载，正在处理文件的部分结果不保留。
- 清空列表仅清空队列。只有外观偏好保存在 `wtools.dbStorage`（独立浏览器预览使用 localStorage）；不保存文档内容。

单文件上限 100 MB，队列合计 200 MB / 50 个文件。不支持加密 PDF。除基本压缩外，单文件单次最多处理 500 页；合并总计最多 500 页。渲染限制为每页 1600 万像素、最长边 8192 像素；预览分辨率更低。图片模式 Office 素材上限 128 MB，单批结果上限 256 MB；大文件请分范围处理。

PDF.js 使用同线程 worker 以兼容 WebView 的本地资源协议，页面任务之间让出事件循环；单个复杂页面解码期间取消可能延迟。提取图片对同一 PDF 资源标识去重，并非按像素查重。Excel 基于文字坐标推断，不等同于表格识别，需核对输出。

## 离线依赖

包内固定版本 PDF.js 4.10.38、pdf-lib 1.17.1、JSZip 3.10.1，含 PDF.js CMap、标准字体及第三方许可证。PDF 解析禁用动态求值；没有 CDN 或在线服务依赖。

重新获取依赖的命令与实现位置见 `scripts/pdf-tools/README.md`。
