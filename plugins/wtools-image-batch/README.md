# 图片批量处理

独立的 WTools 离线 Web 插件，最低宿主版本 0.6.7，无需新增原生接口。所有图片均在本地浏览器内核中处理，不上传服务器。

## 功能

- **图片压缩**：支持 PNG、JPG、JPEG、WebP、TIFF、AVIF、SVG 格式，支持按质量滑块或目标文件大小（KB）压缩；无法继续减小体积时提示「已经达到最大压缩限度」。
- **格式转换**：支持 PNG、JPG、JPEG、WebP、TIFF、AVIF、BMP、GIF、ICO 9 种格式互转。
- **修改尺寸**：支持固定像素宽高（可选保持宽高比）和按百分比缩放。
- **添加水印**：支持文字水印与图片水印，可设置字体大小、缩放、颜色、不透明度、旋转角度、九宫格位置及平铺间距。
- **添加圆角**：支持按百分比（50% 为正圆/椭圆）或固定像素设置圆角，自动保留透明通道。
- **添加边框**：支持外边框与内边框，自定义宽度、颜色及不透明度。
- **补边留白**：支持四边统一、分别设置上下左右或按目标比例补边，支持颜色与透明度（0% 透明留白）。
- **批量裁剪**：支持 1:1、4:3、3:4、16:9、9:16、3:2、2:3 及自定义宽高比裁剪。
- **批量旋转**：支持 -180° 至 180° 任意角度旋转及快捷角度按钮，支持透明、白色或黑色背景。
- **批量翻转**：支持左右水平镜像与上下垂直镜像翻转。
- **合并为 PDF**：支持 A4、A3、A5、Letter 与自适应尺寸，支持无边距/窄边距/宽边距与拖动排序。
- **合并为图片**：支持竖向或横向拼接，可设置间距、背景色、对齐方式及输出格式。
- **合并为 GIF**：将多张图片合成为自动播放 GIF，可调每帧停留时间、循环次数与尺寸适配。
- **手动裁剪**：交互式框选裁剪区域并支持比例锁定，确认裁剪后自动切换至下一张。

## 离线依赖

随包提供 `pako@2.1.0`、`upng-js@2.1.0`、`utif2@4.1.0`、`gifenc@1.0.3`、`pdf-lib@1.17.1`、`jszip@3.10.1`，许可证见 `THIRD-PARTY-LICENSES.txt`。重新下载依赖可执行 `python scripts/image-batch/download_vendor.py`。
