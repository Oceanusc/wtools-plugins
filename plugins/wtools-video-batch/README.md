# 视频批量处理

独立的 WTools 离线 Web 插件，最低宿主版本 0.6.7，基于内置 FFmpeg WebAssembly 与 JSZip 在本地离线处理视频，不上传任何文件。

## 支持功能

- **视频压缩**：仅支持 MP4 视频压缩，可选 H.264 / H.265 编码与 CRF 质量调节。
- **时长裁剪**：支持剪掉片头、剪掉片尾、区间截取、片段裁剪四种模式。
- **画面裁剪**：支持 `16:9`、`4:3`、`3:2`、`5:4`、`1:1` 五种比例及对齐方式。
- **格式转换**：支持 MP4、AVI、FLV、MKV、MOV、WMV、WebM(VP9) 互转。
- **转为动图**：支持 GIF 与 WebP 动图，可配置每秒帧数、输出宽度与循环播放。
- **添加水印**：支持固定位置（九宫格）、动态游走水印、全屏斜向平铺水印，支持文字和图片水印。
- **修改尺寸**：支持指定宽度/高度或常用分辨率预设。
- **视频封面**：支持选择图片作为 MP4 / MKV / MOV 视频封面。
- **视频加速**：支持 0.25x–4.0x 倍速调整，并可同步调整音频速度。
- **视频翻转**：支持左右翻转（水平镜像）、上下翻转（垂直镜像）及双向翻转。
- **视频旋转**：支持任意角度及 90° / 180° / 270° 快捷旋转。
- **视频合并**：支持将视频添加到片头、片尾，或将队列视频合并为一个文件。
- **音频处理**：支持无损删除音频或提取为 MP3 / AAC / WAV。
- **帧提取**：支持设定采样间隔、输出格式（JPG/PNG）和尺寸，并打包为 ZIP 下载。

## 离线依赖

包内包含 `@ffmpeg/core` 0.12.10、`@ffmpeg/ffmpeg` 0.12.15 与 `jszip` 3.10.1，许可证见 `THIRD-PARTY-LICENSES.txt`。可使用 `python scripts/video-batch/download_vendor.py` 重新下载。
