# 颜色助手

WTools 0.6.7 或更新版本可运行此离线插件。打开「设置中心 → 已安装插件 → 注册开发目录」，选择包含 [plugin.json](plugin.json) 的插件目录，然后在启动器搜索「颜色助手」。保存源码后，在插件详情点「重载目录」即可加载新版本。

## 使用方式

- **颜色**：用色轮、滑块或色值输入修改当前颜色，可复制 HEX、RGB、HSV / HSB、HSL、CMYK、HSI 和 LAB（D65）。点击「添加比较色」可以保留当前颜色并创建一个可编辑副本，最多同时比较 8 色。选择参照色可查看对比度和 ΔE₇₆ 色差。启动器支持直接输入 3 位或 6 位 HEX。
- **图片色卡**：选择、拖入图片，或用 Ctrl+V 粘贴截图。色卡提取和像素取色都在本机处理，动图以首帧为准。通过启动器粘贴截图可直接打开色卡。从启动器选择图片文件入口后，在插件内选择或拖入文件读取内容。
- **UI 色卡**：浏览 Flat UI、Fluent Design、Open Color、Ant Design 和 Material Design。
- **传统色**：中国传统色按 24 个节气分组，共 384 色。日本传统色共 465 色。支持按色名、日语读音或 HEX 搜索。
- **渐变色**：按色系浏览预设，或用 2–6 个色标和 0–360° 方向自定义渐变。支持复制 CSS、下载 PNG，宽高各可设置为 1–4096 像素。屏幕取色和复制图片取决于 WebView2 支持及剪贴板权限。
- **收藏颜色**：收藏单色、色板和渐变，按类型查看。开发目录副本与市场安装副本各自保存收藏。

点击任意色卡可查看色值、复制、加入对比或收藏。

## 数据来源

- 中国传统色采用开源 chinacolor 项目整理的《中国传统色：故宫里的色彩美学》色名及 HEX 值，许可证随插件提供。 [chinacolor 数据](https://github.com/zhiming-chen/chinacolor/blob/c64b9ed6c38375c75943baf414784b6b1b98bb50/inst/extdata/chinacolor.json) · [MIT 许可证](LICENSE-chinacolor.md)
- 日本传统色的色名、读音和 HEX 值来自《和色大辞典》。 [和色大辞典](https://www.colordic.org/w)
