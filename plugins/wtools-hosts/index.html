    使用帮助

    编辑、组合、应用

    公共配置首次从系统 hosts 导入，始终参与合并。单击方案进行编辑，勾选参与合并的片段；单选模式只启用一个自定义方案，多选模式按列表顺序合并。保存仅保存方案，应用配置会先展示合并预览。

    双击方案或选择右键菜单的“应用此方案”可快速写入；多选模式会保留其他已勾选方案。检测到冲突时会先打开预览。

    Ctrl / ⌘ S 保存　 Ctrl / ⌘ Enter 预览应用

    hosts 文件不可写？

    打开 C:\Windows\System32\drivers\etc\hosts 的文件属性，取消“只读”。需要时可在“安全 → 编辑”中为当前登录用户勾选“写入”权限，减少重复授权提示。安全软件也可能拦截写入。

    切换后解析没有更新？

    插件不会自动清理 DNS 缓存。可以重新打开无痕窗口；在 Windows 终端运行 ipconfig /flushdns 清理系统 DNS 缓存。浏览器还可能保留自己的 DNS 和连接缓存，需要关闭后重新打开。
