# 编码小助手 1.0

Windows WTools 0.6.7 及更新版本的离线编码工具。插件为原生 HTML/CSS/JavaScript，安装后无需构建或联网，不需要专用原生接口或包指纹。只保存主题偏好，不保存输入文本、文件或转换历史。

## 使用

在 WTools「设置中心 → 已安装插件」注册本目录，重新加载后输入「编码小助手」打开。也可使用各工具关键词进入。左侧选择工具，输入或选择文件，点击处理按钮；Ctrl+Enter 同样执行。结果可整体复制，多项结果可逐项复制。

| 工具 | 功能 |
| --- | --- |
| Base64 | UTF-8 字符串编码、解码，支持中文、Emoji 和缺省末尾补位；严格校验编码，不把任意二进制误作文本 |
| 图片 Base64 | 选择/拖入图片编码为 Data URL 或纯 Base64；解码后预览与保存；支持 PNG/JPEG/GIF/WebP/BMP/ICO，最大 16 MiB |
| 时间转换 | 当前时间戳、秒/毫秒、日期、ISO 8601、本地时间、UTC、GMT；严格校验日期 |
| UUID / GUID | 使用 `crypto.getRandomValues` 生成 UUID v4；单次 1–100 个，大小写、连字符与大括号可选 |
| Hash | MD5、SHA1、SHA224、SHA256、SHA384、SHA512；文本 UTF-8 或本地文件；支持全部算法同时计算 |
| URL | `encodeURIComponent` / `decodeURIComponent` 参数模式和 `encodeURI` / `decodeURI` 完整 URL 模式 |
| 进制 | 2–36 进制正负整数转换，使用 BigInt 保留精度；展示目标进制及常用进制 |
| Unicode | 码位 `U+`、码位转义 `\u{…}`、UTF-16 `\uXXXX`、UTF-8 `\xXX`、HTML 数字实体 |
| HTML | `& < > " '` 特殊字符转义、命名与数字实体解码；输入按文本处理 |

Hash 是单向摘要，不是可逆加密。文件通过浏览器 File 对象读取，最大 1 GiB；后台 Worker 每次读取 2 MiB，可取消。空文件与空文本也可计算摘要。选择多个算法会增加计算时间。

时间戳自动单位按数值判断：绝对值小于 1000 亿视为秒，否则视为毫秒。历史毫秒时间戳和特殊年份请显式选择单位。没有时区的日期使用当前系统本地时区，也可选择 UTC；自带 `Z` 或 `±HH:mm` 的时间按自身时区解释。Unix 秒向下取整。

URL 中的 `+` 保持字面含义，不自动视为空格。HTML 实体单次解码，避免递归解码；HTML 转义与 Unicode 的数字实体编码分别提供。

## 启动器自动识别

清单声明 Rust regex 指令，匹配后在启动器选择相应工具，将原文带入插件处理：

- Base64 字符串与图片 Data URL；剪贴板图片也可直接进入图片编码。
- 10 位秒时间戳、13 位毫秒时间戳（可负数），以及 `YYYY-MM-DD HH:mm:ss` / ISO 8601。
- URL 百分号编码、`0x` 十六进制整数。
- `\uXXXX`、`\xXX`、`U+XXXX`、`\u{…}` 与 HTML 命名/数字实体。

Base64 与普通字母数字文本可能重合，建议通过格式与解码结果确认。插件内「智能识别」仅把有效 UTF-8 文本识别为字符串 Base64；非文本内容请手动选择图片工具。

在插件详情开启「搜索栏推送」，使用聚合搜索可预览识别到的文本转换结果。预览最多处理 4096 字符，显示前 160 字符；选择后在插件内查看完整内容。图片、文件摘要与 UUID 不在隐藏窗口中预计算。普通正则入口受宿主 64 KiB 输入上限约束，大图片或长文本请在插件内粘贴。宿主限制本地文件路径的直接读取，文件摘要必须在插件窗口选择或拖入文件。

## 文件与依赖

- `plugin.json`：功能入口与自动识别规则。
- `index.html`、`style.css`、`index.js`：界面、主题、文件处理与宿主生命周期。
- `converters.js`：文本、日期、进制与图片转换。
- `hash-worker.js`：后台文件分块摘要。
- `vendor/crypto-js.js`：CryptoJS **4.2.0**，来源为 npm 官方版本 `https://registry.npmjs.org/crypto-js/-/crypto-js-4.2.0.tgz`；MIT 许可证保留在 `vendor/LICENSE.crypto-js`。

运行资源均随包提供，无外部脚本、字体或网络调用；兼容宿主 `script-src 'self'` 和 `worker-src 'self'`。发布时沿用仓库统一目录构建流程。

窗口高度不超过 360 逻辑像素时，通过标题行「选项」展开转换设置，Escape 或点击外部收起，为输入和结果保留编辑空间。已在 410×300 的实际 WTools WebView2 中检查全部九种工具、选项修改和 Base64 执行，并运行浏览器功能与多尺寸回归。文件摘要、图片处理和启动器匹配/推送的自动验证使用隔离样本。
