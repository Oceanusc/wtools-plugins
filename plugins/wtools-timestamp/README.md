# 时间戳转换

离线运行的 WTools Web 插件。启动器输入「时间戳转换」「时间戳」「timestamp」或「sjc」打开。

- 支持秒、毫秒与日期双向转换；切换单位时保留时间戳输入代表的同一时刻。
- 日期格式为 `YYYY-MM-DD HH:mm:ss`，可附加 `.SSS` 毫秒；也可通过日历选择。秒时间戳支持最多三位小数，毫秒须为整数，支持负数及 Unix 纪元 `0`。
- 按所选 IANA 时区解释日期。默认北京（Asia/Shanghai），时区下拉显示当前 UTC 偏移，转换区显示输入日期对应的偏移。
- 对非法日期、范围外时间戳、夏令时跳过或回拨造成的不存在/重复时间提示错误。支持公元 0001 至 9999 年；对于回拨产生的重复日期，请改用 UTC 日期或直接输入时间戳。
- 点击转换结果或当前时间戳复制；在输入框外使用 `Ctrl/Command + Shift + Z` 复制日期转时间戳结果，`Ctrl/Command + Shift + X` 复制时间戳转日期结果。输入框中保留原有编辑快捷键。
- 当前时间戳可暂停、继续；“使用当前时间”填入日期输入框。秒模式的实时时间戳显示整数，毫秒模式每 100ms 刷新。
- 设置支持搜索和勾选主页时区、跟随系统/浅色/深色主题。保存后生效，取消放弃草稿，恢复默认也需保存后生效。

使用浏览器内置 `Intl` 时区数据库，不依赖联网资源或额外框架。时区数量取决于宿主 WebView 的版本；常用城市提供中文名，其他时区可按英文城市名、UTC 偏移或完整 ID 搜索。

设置优先使用 WTools `dbStorage`，普通浏览器预览回退至 `localStorage`；复制优先使用宿主 `copyText`。读取失败时暂停写入，避免覆盖原有设置。时间戳输入内容不持久化。

目录中均为可直接加载的静态文件，无需构建。最低 WTools 版本沿用普通离线 Web 插件的 0.6.7；无需专用原生接口。本次按用户约定未运行测试、构建、代码审核或宿主验收。
