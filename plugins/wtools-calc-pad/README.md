# 计算稿纸 (wtools-calc-pad)

高效简洁的计算工具，实时计算、自动保存，像稿纸一样记录每一步过程。

## 快捷键

- `Enter`：将当前计算结果带入下一行继续计算
- `↑` / `↓`：快速切换计算行
- `Ctrl / Cmd + C`：未选中文本时复制当前计算结果
- `Ctrl / Cmd + B`：为当前计算添加或编辑备注
- `Ctrl / Cmd + N`：新建稿纸
- `Ctrl / Cmd + R`：清空当前稿纸

## 支持的表达式

- 基础运算：`+`、`-`、`*` / `×` / `x`、`/` / `÷`、`^` / `**`、`%`（百分号）
- 括号与格式：`()` / `（）`、全角运算符、千分位逗号（如 `1,942`）
- 常量：`pi` / `π`、`e`、`tau`
- 函数：`abs`、`sqrt`、`cbrt`、`round`、`floor`、`ceil`、`sin`、`cos`、`tan`、`asin`、`acos`、`atan`、`ln`、`log`、`log2`、`exp`、`pow`、`min`、`max`、`sum`、`avg`
