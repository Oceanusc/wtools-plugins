# 欢迎使用 Markdown 笔记

让思绪有处安放，让记录自然发生。

> 每一个好想法，都值得被认真记下。现在就开始你的第一篇笔记。

## 一处书写，三种体验

在上方切换 **所见即所得**、**即时渲染** 和 **源码 / 预览**，找到适合自己的节奏。内容会自动保存到 WTools 本地数据库。

| 你想做什么 | 试试这样 |
| --- | --- |
| 强调一段文字 | **加粗**、*斜体*、~~删除线~~ |
| 记录一段代码 | 使用代码块，自动高亮 |
| 搜索所有笔记 | 按 `Ctrl + F`，输入标题或内容 |
| 整理笔记 | 新建文件夹，拖动归档 |

## 今天的小计划

- [x] 找到一个安静的记录空间
- [ ] 记下今天最重要的一件事
- [ ] 把灵感变成行动

## 代码也能清晰表达

```javascript
const ideas = ['记录', '思考', '创造'];
ideas.forEach(idea => console.log(`今天，从${idea}开始。`));
```
